## Inter-Service Communication

### Synchronous HTTP

- Immediate request and response
- Easy to implement
- Tight coupling between services
- If one service is down, dependent requests fail

### Asynchronous Messaging

- Loose coupling
- Better scalability
- Services communicate through a message broker
- Common tools: RabbitMQ and Kafka
- Suitable for notifications, email, logging, and background processing
